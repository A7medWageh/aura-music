# Aura Music Mobile (React Native / Expo iOS)

تطبيق الهاتف المحمول الأصلي والمنفصل كلياً لخدمة **Aura Music**، مبني باستخدام React Native و TypeScript و Expo Router، ومصمم خصيصاً ليعمل بأعلى كفاءة على أجهزة iPhone ونظام iOS بدون إنترنت مع دعم التشغيل في الخلفية وشاشة القفل وسماعات AirPods.

---

## 🌟 الميزات الجوهرية (Core Features)

### 1. بنية متكاملة للعمل بدون إنترنت (Full Offline-First Architecture)
- **تخزين الملفات الأصلي (Native FileSystem)**: يتم تحميل المقاطع الصوتية وحفظها محلياً ودائماً داخل `FileSystem.documentDirectory/aura_audio/` كملفات مستقلة بصيغة MP3، دون الاعتماد على Blob URLs أو Cache المتصفح المؤقت.
- **قاعدة بيانات SQLite محلية مستمرة**: تخزين شامل لجميع بيانات الأغاني المحملة، وقوائم التشغيل (Playlists)، والمفضلة (Favorites)، وكلمات الأغاني المزامنة (LRC)، وسجل الاستماع، وجلسة التشغيل السابقة لاستعادتها فور فتح التطبيق.
- **تشغيل بدون إنترنت بنسبة 100%**: يفحص مشغل الصوت أولاً وجود الملف الصوتي محلياً على الهاتف، وفي حال وجوده يعمل مباشرة من مسار الملف المحلي (`file://...`) دون إرسال أي طلب شبكة إطلاقاً.
- **التحقق من سلامة الملفات**: فحص تلقائي لحجم الملف (>30KB) لمنع تخزين ملفات تالفة أو ناقصة.
- **إدارة التخزين (Storage Management)**: بطاقة تفاعلية تعرض مساحة الذاكرة المستهلكة وعدد الأغاني المحفوظة مع إمكانية حذف أي أغنية محملة بضغطة واحدة.

### 2. مشغل الصوت الأصلي ودعم خلفية iOS (Native Audio & Background Playback)
- **تشغيل في الخلفية وشاشة القفل**: مهيأ بإذن `UIBackgroundModes: ["audio"]` و `playsInSilentModeIOS: true` و `staysActiveInBackground: true` ليستمر الصوت في العمل عند إقفال شاشة الهاتف، أو التنقل بين التطبيقات.
- **التحكم عبر AirPods و Bluetooth**: دعم كامل لأزرار التحكم بالسماعات (Play / Pause / Next / Prev).
- **استئناف الجلسة (Session Restoration)**: يحفظ المشغل تلقائياً آخر أغنية وقائمة الانتظار وموضع التشغيل بالثانية، ويستعيدها عند فتح التطبيق مجدداً.
- **مشغل مصغر (Mini Player)**: شريط مدمج فوق التبويبات السفلية يتيح التحكم السريع وشريط تقدم لحظي.
- **مشغل كامل فائق (Full Player Modal)**:
  - غلاف الألبوم بدقة عالية مع توهج خفيف وتصميم Aura الليلي المميز.
  - شريط تحكم بالثواني (Scrubber).
  - أوضاع التكرار (Repeat One, Repeat All, Off) والخلط العشوائي (Shuffle).
  - قائمة الانتظار الحية (Live Queue).

### 3. كلمات الأغاني المزامنة (Synced Lyrics - LRC)
- دعم قراءة الكلمات المزامنة بنظام LRC سطر بسطر.
- تمرير تلقائي وتلوين السطر النشط بتوهج السيان المميز لأورا.
- حفظ الكلمات محلياً في SQLite للوصول إليها بدون إنترنت بعد أول قراءة.
- التبديل السلس بين شاشة الغلاف وشاشة الكلمات داخل المشغل.

### 4. الهوية البصرية والتصميم (Aura Music Identity)
- الحفاظ التام على ألوان أورا الليلية: الأسود الفاحم `#000000`، والأسطح المرتفعة `#0d1117`، مع لون السيان التوقيعي الفائق `#00e5ff` ولون النيلي `#6366f1`.
- دعم كامل للغة العربية واتجاه القراءة والخطوط والأيقونات.

## 🚀 تشغيل وتطوير التطبيق (Running the Project)

### المتطلبات المسبقة:
- Node.js (v20+ أو أحدث).
- تطبيق Expo Go على هاتف iPhone أو محاكي iOS (Xcode على Mac).

### 1. الانتقال إلى مجلد التطبيق:
```bash
cd aura-music-mobile
```

### 2. بدء خادم التطوير:
```bash
npm start
```
أو
```bash
npx expo start
```

امسح رمز الـ QR الظاهر باستخدام كاميرا الـ iPhone لفتح التطبيق مباشرة في تطبيق **Expo Go**.

## 🍎 بناء نسخة الإنتاج لـ iPhone (Building for iOS / IPA)

لبناء ملف IPA أصلي جاهز للرفع على App Store أو TestFlight باستخدام خدمة Expo Application Services (EAS):

1. **تثبيت أداة EAS CLI**:
   ```bash
   npm install -g eas-cli
   ```

2. **تسجيل الدخول في Expo**:
   ```bash
   eas login
   ```

3. **إعداد مشروع البناء**:
   ```bash
   eas build:configure
   ```

4. **بدء بناء نسخة الـ iOS في السحابة**:
   ```bash
   eas build --platform ios --profile production
   ```

يقوم هذا الأمر بتجميع التطبيق في بيئة macOS سحابية، ودمج إعدادات الـ Background Audio وتوقيعه بشهادة المطور الخاصة بك لتوليد ملف الـ IPA.
